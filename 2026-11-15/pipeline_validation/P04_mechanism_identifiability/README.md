# P04 · Mechanism identifiability: can six simulated circuit mechanisms be told apart?

**Question.** Six candidate mechanisms could change gamma in AD:
- loss of synapses onto PV cells;
- PV output (Nav1.1) loss;
- SST interneuron loss;
- erratic excitatory drive;
- tau-related silencing;
- cholinergic loss.

If each is simulated, do the EEG features they produce ("fingerprints") differ enough to tell which one is present?
**Type.** Pipeline validation. Simulated circuits only. No labels.
**When / where.** Final run on the laptop, 14 Nov 2026.

**What was run.** Two simulator families were run at increasing severity for each mechanism:
- **rate:** a population-rate model;
- **cycle:** a cycle-level model.

The pipeline's features were measured on the simulated signals. The script then checked whether each mechanism's fingerprint could be recovered from simulated data generated by the same family and by the other family. Details are in `../../code/neurohertz_v2_frozen/docs/MECHANISMS.md`.

**Command.** `python scripts/13_mechanism_fingerprints.py --jobs 8`
**Code.** `../../code/neurohertz_v2_frozen/scripts/13_mechanism_fingerprints.py`, `../../code/neurohertz_v2_frozen/nh/mechsim.py`, `nh/cyclemodel.py`, `nh/fingerprint.py`

| Output in `results/` | Content |
|---|---|
| `fingerprints.csv` / `.json` | Each mechanism's effect on each feature, per family |
| `agreement.csv` | Whether the two families agree on each feature's direction |
| `separability.csv` | Pairwise cosine similarity of mechanism fingerprints |
| `identifiability.json` | Confusion matrices and recovery accuracy for every family × data combination |
| `sim_features.csv` | Raw simulated feature values |
