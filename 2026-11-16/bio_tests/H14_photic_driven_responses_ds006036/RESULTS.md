# Results · H14

## Main results
- **Reliable cells:** only four have reliable responses in CN.
- **No gamma harmonics:** every 30–45 Hz harmonic falls below 3 dB SNR in CN.

| Response | AD − CN | SNR AD / CN |
|---|---|---|
| 10 Hz drive | −3.0 ± 1.2 dB | 6.4 / 6.3 dB |
| 15 Hz drive | −0.7 ± 1.2 dB | 5.7 / 5.6 dB |
| 20 Hz (2nd harmonic of 10 Hz) | −3.8 ± 1.4 dB | 4.6 / 6.1 dB |
| 20 Hz drive | −2.0 ± 1.3 dB | 5.1 / 5.7 dB |

- **Mechanism test (f ≥ 14 Hz, 3 cells):**

| Model | χ² |
|---|---|
| uniform reduction | 2.9 |
| M4 | 1.0–1.6 |
| M1 reversed | 0.9–1.6 |
| M2 | 1.3–1.8 |

- **Within-person link:** resting beta vs 15–20 Hz driven power, ρ ≈ 0.05–0.27.

## Consequences
- **What the data show:** driven power is lower in AD at 10 and 20 Hz while **SNR is unchanged**, so the driven and spontaneous activity shrink together. This is what one shared transfer-function change predicts.
- **The protocol can't separate the mechanisms:**
    - 10-s blocks, so about 5 epochs and SE ≈ 1.2 dB;
    - no measurable gamma harmonics;
    - predicted differences of only 1–2 dB.

    Separating them takes longer blocks and drives that reach 30–45 Hz (H17 quantifies this).
